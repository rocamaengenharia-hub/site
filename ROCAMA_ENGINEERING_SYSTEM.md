# ROCAMA ENGENHARIA – SISTEMA WEB OFICIAL

## Visão Geral
Sistema web composto por um site institucional e um painel administrativo,
desenvolvido para centralizar orçamentos, serviços, clientes e conteúdo do site.

## Stack
- Frontend: React + TypeScript
- Backend: Supabase (Postgres, Auth, Storage) via MCP
- UI/UX: Design profissional inspirado em escritórios premium de engenharia
- Deploy: Google Antigravity

## Módulos do Admin

### Dashboard
- Métricas diárias, semanais e mensais
- Orçamentos recebidos
- Orçamentos aceitos e recusados
- Visão rápida do negócio

### Orçamentos
- Recebimento via formulário do site
- Status: Recebido | Aceito | Recusado
- Tabela com dados completos
- Visualização detalhada

### Clientes
- Cadastro automático ao solicitar orçamento
- Histórico de solicitações

### Serviços
- CRUD completo de serviços
- Status ativo/inativo
- Linha do tempo com imagens e vídeos
- SEO configurável

### Layout do Site
- Edição das páginas:
  - Home
  - Serviços
  - Portfólio
  - Contato
- Gerenciamento de textos e imagens
- Linha do tempo visual nos projetos

### Configurações
- Dados da empresa
- Logo
- Título do site
- Descrição
- Configurações globais

## Diretrizes
- Código modular e escalável
- Tipagem forte
- Segurança com RLS
- UX simples e intuitiva
